01 — About

Where hardware meets infrastructure.

I'm a computer science student at Gauhati University and a DevOps engineer at VrixaaLabs. My projects start at the workbench with a microcontroller, a soldering iron, and a bad idea. They end up deployed, monitored, and version-controlled.

Right now I'm building CI/CD pipelines at work, leading hackathons on the side, and running a small datacenter's worth of self-hosted services out of my room in Guwahati.

Solder side

Firmware in C and C++ on ESP32 and RP2040: BLE keyboards, HID devices, field sensors, and security keys. Bare metal, no OS, every byte accounted for.

  • C / C++
  • ESP32
  • RP2040
  • BLE HID
  • PlatformIO

Deploy side

Docker, Proxmox, pfSense, Cloudflare, and Grafana. These run the dashboards my devices report to, all self-hosted, tunneled, and redeployed on every git push.

  • Docker
